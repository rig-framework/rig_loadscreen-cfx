# rig_loadscreen-cfx

A simple load screen built for RIG - CFX platforms (FiveM/RedM).

## Configuration

- `/ui/config.js`

```js
const config = {
    locale: 'en', // Language file to load from ./locales/{locale}.json
    is_dev_mode: false // Set to true for browser testing / local preview
};
```
